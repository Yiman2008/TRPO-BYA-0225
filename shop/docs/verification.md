# Результаты проверки практических работ №7–11

Дата: 9 ноября 2026. Локальное окружение: Windows, PHP CLI 8.4.27. Проверки выполнялись на исходных данных архивов.

| Проверка | Команда из shop | Результат |
|---|---|---|
| Синтаксис | php tests/lint.php | 37 файлов, ошибок нет |
| Каталог, корзина, заказ, ошибки сохранения | php tests/run.php | 23 проверки пройдены |
| Архитектурный checklist | php tests/architecture.php | 8 пунктов пройдены |
| HTTP-регрессия | php tests/http.php | 39 проверок пройдены, PHP warnings отсутствуют |

Каталог содержит 24 товара, категория книг — 6, неизвестная категория — 0. Сортировка по цене соответствует возрастанию. Все три сценария корзины сверены по состоянию, количеству и сумме на наборе товаров №9.

В заказах проверены пустая форма, неверный email, неизвестная доставка, отсутствие адреса курьера, правильный заказ, стоимость доставки, сохранение серверных цен, сохранность предыдущих заказов и сохранение корзины при повреждённом JSON. Корректный самовывоз из исходного `order_cases.json` проходит без ввода адреса: пункт выдачи фиксирован в форме и заказе.

HTTP-тест использует настоящий встроенный сервер PHP, отдельную сессию и временное хранилище заказов. Выполнены все строки route_tests.csv. Для POST /cart/add подаются корректные product_id и CSRF, ожидаемый статус — 302. Отдельно проверены 403 для неверного CSRF, 405 для GET изменения, 404 для неизвестных id, 422 для ошибочных типов и количества.

Проверена защита от HTML в повторно показанной форме, отсутствие контакта на подтверждении, изоляция подтверждения между сессиями, однократность flash, отсутствие повторного заказа при обновлении подтверждения и недоступность dataset/var из public.

В браузере просмотрены каталог, добавление товара в корзину и форма оформления. Макет отображается без видимых наложений на проверенной ширине. Узкий экран использует CSS-перестроение сетки и горизонтальную прокрутку таблицы; отдельная визуальная проверка мобильного размера не проводилась.

Автоматические проверки намеренно не подменяют демонстрацию на защите. GitHub Actions настроен для PHP 8.1 и 8.4; фактический статус удалённого запуска следует смотреть на вкладке Actions репозитория.
