# Практическая работа №7

Создан каркас интернет-магазина. Единая точка входа — `public/index.php`, зависимости собираются в `Core/Application.php`. Маршруты читаются из `dataset/pr07/routes.csv`, содержимое главной — из `pages.json`, логотип используется в общей шапке.

| Метод и адрес | Контроллер | Представление |
|---|---|---|
| GET / | HomeController::index | home |
| GET /catalog | CatalogController::index | catalog |
| GET /about | HomeController::about | about |
| GET /missing | ErrorController::notFound | error, статус 404 |
| GET /любой-неизвестный | общий обработчик | error, статус 404 |

Router выбирает действие без HTML; контроллер передаёт готовые данные в View. View подключает шаблон и общий layout. Конструкторы получают реальные зависимости: View — каталог шаблонов, контроллеры — View.

Запуск из `shop`: `php -S 127.0.0.1:8000 -t public public/router.php`. Открыть http://127.0.0.1:8000. Требуется PHP 8.1 или новее. Состояние этого этапа сохранено тегом `pr07-complete`.

На этапе №7 каталог содержит три тестовых товара. Работа №8 заменяет их моделями из JSON. Последующие этапы продолжают этот же проект; итоговые инструкции находятся в `shop/README.md`.
