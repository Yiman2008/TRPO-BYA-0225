# Практическая работа №9

Продолжение магазина; тег перед началом — `pr08-complete`, итог этапа — `pr09-complete`.

Выбран CartService: сервис отвечает за количество и расчёт сумм, а Session — за хранение между HTTP-запросами. Поэтому CartService можно проверить без браузера и без `$_SESSION`.

Session запускается централизованно в Application. В ключе `cart` хранится только `product_id => quantity`; полные товары и цены всегда берутся из ProductRepository. `summary()` единожды рассчитывает строки, их стоимость, общее количество и итоговую сумму.

GET `/cart` показывает пустое состояние или таблицу. POST `/cart/add`, `/cart/update`, `/cart/remove` проверяют CSRF, целочисленный id и количество, затем сохраняют состояние и возвращают 302 на `/cart`. Обновление страницы не повторяет действие. Flash извлекается один раз в начале следующего запроса; счётчик виден в общем layout.

Все три сценария `cart_scenarios.json` запускаются тестом `php tests/run.php` на `dataset/pr09/products.json`: итоговые суммы — 4300, 0 и 12900 рублей. В основном каталоге остаются 24 товара работы №8: отдельный набор №9 не перезаписывает их. У fixture №9 нет stock, поэтому для него запас не ограничивается; в основном каталоге stock проверяется.

Для проверки новой сессии откройте `/cart` в приватной вкладке: отображается пустая корзина без предупреждений. Все действия изменения доступны только через POST.
