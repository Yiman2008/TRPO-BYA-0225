# Практическая работа №8

Продолжение работы №7 в папке `shop`, состояние этапа — тег `pr08-complete`.

`Product(id, name, price, Category, stock)` и `Category(id, name)` — модели без HTTP-глобальных переменных. `ProductRepository` читает `dataset/pr08/products.json` и `categories.json`, связывает товар с категорией по `category_id`. Цены хранятся целым числом рублей; `money()` форматирует вывод.

Путь запроса: `public/index.php → Application → Router → CatalogController → ProductRepository → Product/Category → View → layout`.

`GET /catalog?category=1&sort=price` фильтрует книги и сортирует по цене, `sort=name` — по названию с естественным порядком чисел. Фильтр сохраняется в URL. Неизвестная категория возвращает пустой список; неизвестный товар `/product?id=99999` — 404. Некорректный тип параметра — 422.

Сценарии `catalog_cases.csv`: все товары — 24, категория 1 — 6, категория 99 — 0. Проверки итогового проекта: `php tests/run.php`.

Запуск из `shop`: `php -S 127.0.0.1:8000 -t public public/router.php`.
