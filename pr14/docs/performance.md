# Измерение фильтрации

`npm run measure`, Node.js 24.22.1. Время — медиана 15 прогонов, в миллисекундах.

| Сценарий | Два вызова на состояние | Один вызов на состояние |
|---|---:|---:|
| 1000 элементов, один фильтр | 2 прохода · 0,588 мс | 1 проход · 0,293 мс |
| 1000 элементов, 50 переключений | 100 проходов · 27,952 мс | 50 проходов · 14,086 мс |

Скрипт моделирует работу фильтра и проверяет одинаковый результат в обеих версиях. Абсолютное время зависит от компьютера.

## Размер production-сборки

GitHub Actions подтвердил, что сборка проходит. Основной JS — 68 726 байт (27 512 байт gzip), CSS — 1 056 байт (587 gzip), отдельный модуль исходных данных — 454 байта (161 gzip).
