# Практическая работа №12 — Vue Options API

Каталог задач с поиском, фильтром по статусу, добавлением и отметкой выполнения.
Начальный каркас соответствует проекту Vue + Vite из команды `npm create vue@latest`.

## Запуск

Нужен Node.js 22.18+ (22.x) или 24.12+ и npm.

```sh
npm install
npm run dev
npm test
npm run build
npm run preview
```

`dataset/items.json` загружается при `mounted`, `filters.json` задаёт порядок и подписи фильтров, `ui_states.json` управляет демонстрацией состояний через `?state=loading|error|empty|success`.

## Как устроено приложение

`data` содержит список, строку поиска, статус и признаки загрузки. `computed` формирует видимый список и счётчик. `methods` добавляет задачу и меняет статус. `props` передают записи и подписи в список и карточку. `emits` передают владельцу состояния идентификатор задачи или новое значение фильтра. `mounted` загружает данные.
