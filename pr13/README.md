# Практическая работа №13 — Vue Composition API

Миграция каталога №12 на Composition API. Запуск из этой папки через `npm install`, `npm run dev`. Проверки — `npm test` и `npm run build`. Требования к Node.js указаны в `package.json`. Запускайте из полной копии репозитория, так как демонстрационный сценарий использует dataset №12.

## Сравнение по migration_map.csv

| Options API в №12 | Composition API в №13 | Участок проекта |
|---|---|---|
| data | ref | Список, фильтр и загрузка в useItems |
| computed | computed | Видимые задачи и счётчик |
| methods | functions | add и toggle в useItems |
| mounted | onMounted | App запускает загрузку |
| props | defineProps | ItemList принимает массив задач |
| emits | defineEmits | ItemCard передаёт идентификатор задачи |

Composable объединяет загрузку, реактивное состояние и операции над задачами. App связывает его с компонентами, а ItemForm отвечает за ввод и проверку названия.

## Проверка миграции

Обычный запуск загружает десять записей из `items.json`. Для сравнения с №12 откройте `?state=options`: действуют те же 12 исходных задач, фильтры, поиск, добавление и отметка выполнения. Сценарии `?state=empty_list` и `?state=missing_optional` читают `edge_cases.json`. В первом виден пустой список, во втором запись получает статус «Новые» и приоритет 1. Сценарии загрузки, ошибки и пустого состояния №12 также перенесены.
