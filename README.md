# Информационный портал факультета

Учебный проект по дисциплине **ТРПО** (практическая работа №1 — HTML и CSS).

Это простой одностраничный сайт: на нём есть список курсов, таблица с расписанием и форма обратной связи. Сайт сделан только на **HTML** и **CSS** — без JavaScript, без фреймворков и без установки чего-либо.

---

## Что есть на сайте

- **Шапка** — логотип и меню со ссылками на разделы страницы.
- **Курсы** — шесть карточек: название, описание, категория и цена курса.
- **Расписание** — таблица с курсами, категориями, стоимостью и длительностью в часах.
- **Обратная связь** — форма с полями «Имя», «Email», «Возраст», «Интересующий курс» и «Комментарий». Браузер сам проверяет, что поля заполнены правильно (например, что email похож на email).
- **Подвал** — информация о проекте.

---

## Как открыть сайт

Ничего устанавливать не нужно.

### Вариант 1. Скачать архивом (самый простой)

1. На странице репозитория на GitHub нажмите зелёную кнопку **Code**.
2. Выберите **Download ZIP**.
3. Распакуйте архив в любую папку.
4. Откройте файл `index.html` двойным щелчком — сайт откроется в браузере.

### Вариант 2. Через Git

Если у вас установлен [Git](https://git-scm.com/downloads), выполните в терминале:

```bash
git clone https://github.com/Yiman2008/TRPO-BYA-0225.git
cd TRPO-BYA-0225
```

После этого откройте файл `index.html` в браузере.

> **Совет:** если вы пользуетесь редактором VS Code, установите расширение **Live Server**. Тогда можно нажать правой кнопкой по `index.html` → **Open with Live Server**, и страница будет сама обновляться после каждого сохранения.

## Структура проекта

```
TRPO-BYA-0225/
├── index.html            ← главная (и единственная) страница сайта
├── css/
│   └── styles.css        ← все стили: цвета, отступы, карточки, таблица, форма
├── images/
│   ├── logo.svg          ← логотип в шапке
│   └── cover.svg         ← картинка-обложка на главном экране
├── data/
│   ├── content.csv       ← список учебных тем (таблица, разделитель «;»)
│   └── navigation.json   ← пункты меню в формате JSON
├── .gitignore            ← файлы, которые Git не должен отслеживать
└── README.md             ← этот файл
```

Файлы в папке `data/` пока не подключены к странице — это заготовка данных на будущее (например, чтобы потом выводить меню и карточки с помощью JavaScript).

## Как что-то поменять

| Что хочу изменить | Где это сделать |
|---|---|
| Текст, заголовки, карточки курсов, строки таблицы | `index.html` |
| Цвета, шрифты, размеры, отступы | `css/styles.css` |
| Логотип или обложку | заменить файлы в папке `images/` (имена файлов лучше оставить теми же) |

Пример: чтобы добавить новый курс, скопируйте в `index.html` один блок `<article class="card"> ... </article>`, вставьте его рядом с остальными и поменяйте текст внутри. Оформление подхватится автоматически.

После изменений просто сохраните файл и обновите страницу в браузере (клавиша **F5**).

---

## Использованные технологии

- **HTML5** — разметка страницы (семантические теги `header`, `nav`, `main`, `section`, `article`, `footer`).
- **CSS3** — оформление и адаптивная вёрстка.
- **SVG** — картинки, которые не теряют качество при увеличении.
