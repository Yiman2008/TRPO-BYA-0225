## Запуск магазина работ №7–11

Требуется PHP 8.1+. Работы последовательно развивают один проект, этапы сохранены тегами `pr07-complete` — `pr11-complete`, итоговая версия — `shop-v1.0.0`.

```bash
cd shop
php -S 127.0.0.1:8000 -t public public/router.php
```

Открыть http://127.0.0.1:8000. [Полная инструкция, архитектура, dataset и проверки](shop/README.md). Исходные работы №1–6 сохранены. GitHub Pages не запускает PHP; магазин нужно запускать через PHP.

## Структура проекта
```
TRPO-BYA-0225/
├── index.html            ← главная (и единственная) страница сайта
├── css/
│   └── styles.css        ← все стили: цвета, отступы, карточки, таблица, форма
├── images/
│   ├── logo.svg          ← логотип в шапке
│   └── cover.svg         ← картинка-обложка на главном экране
├── data/
│   ├── content.csv       ← список учебных тем (таблица, разделитель «;»)
│   └── navigation.json   ← пункты меню в формате JSON
├── .gitignore            ← файлы, которые Git не должен отслеживать
└── README.md             ← этот файл
```
