# Практическая работа №15 — Погодный менеджер

Vue и Open-Meteo. Выбор города, текущая погода, прогноз на три дня, повторная загрузка и автономный режим.

```sh
npm install
npm run dev
npm test
npm run build
npm run preview
```

`cities.csv` задаёт названия, координаты и часовые пояса. `api_fields.json` задаёт подмножества current и daily. `weather_codes.json` задаёт подписи кодов, неизвестные коды получают резервную подпись. `mock_forecast.json` содержит прогноз для режима без API.

## API

Пример запроса для Москвы:

```text
https://api.open-meteo.com/v1/forecast?latitude=55.7558&longitude=37.6176&timezone=Europe%2FMoscow&current=temperature_2m%2Cweather_code%2Cwind_speed_10m&daily=weather_code%2Ctemperature_2m_max%2Ctemperature_2m_min&forecast_days=3&wind_speed_unit=kmh
```

`current` содержит температуру, код и скорость ветра. В `daily` дата из `time[i]`, минимальная и максимальная температура и код берутся по одному индексу. Ответ с ошибкой HTTP, неверным JSON или несовпадающими массивами переводит интерфейс в ошибку.

## Сценарии

- Нажмите «Загрузить прогноз» без города. Появится сообщение у области результата.
- Выберите город. В Network виден запрос с координатами, блокируется повторная загрузка, в конце видны карточки и время обновления.
- Включите «Деморежим без API» и выберите город. Карточки выводятся из локального примера с явной пометкой.
- В Network включите Offline и нажмите «Обновить» в режиме API. Интерфейс покажет ошибку сети. Верните сеть и повторите запрос.
